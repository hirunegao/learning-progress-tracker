# 📋 スタッフ学習進捗票

**DMM 生成AI CAMP — learningBOX 全8コース対応の学習進捗管理ツール**

## 概要

スタッフがDMM生成AI CAMPの各コースの学習進捗をチェックリスト形式で管理できるWebアプリケーションです。ブラウザだけで動作し、サーバー不要のシングルHTMLファイルです。

## 対応コース（全8コース）

| コース名 | コンテンツ数 |
|---------|-----------|
| PE-基礎マスターコース | 49 |
| PE-マーケティングコース | 43 |
| PE-営業コース | 31 |
| PE-人事コース | 44 |
| 生成AIエンジニアコース | 146 |
| Difyマスターコース | 182 |
| 生成AIデザインコース | 63 |
| 生成AI動画クリエイターコース | 134 |

## 機能

- ✅ **チェックリスト式進捗管理** — レッスン・チャプター単位で完了をチェック
- 📅 **完了日の自動記録** — チェック時に自動で今日の日付を記録
- 📊 **サマリーダッシュボード** — 全体進捗率・完了チャプター数・完了コース数をリアルタイム表示
- 🔍 **コースフィルタリング** — 特定のコースだけを表示
- 💾 **データ保存/読込** — JSONファイルでスタッフ別にデータを保存・復元
- 📊 **CSV出力** — Excelで開ける形式でエクスポート
- 🖨️ **印刷対応** — 紙に出力してファイリング可能
- 📱 **レスポンシブ対応** — スマホ・タブレットでも利用可能

## 使い方

1. `index.html` をブラウザで開く
2. スタッフ氏名・部署・受講開始日を入力
3. 各コースをクリックして展開し、学習完了したチャプターにチェック
4. 「保存」ボタンでJSONファイルとして保存（スタッフごとに管理可能）

## 技術仕様

- **HTML/CSS/JavaScript** のみで構成（サーバー不要）
- **localStorage** でブラウザにデータを保存
- 外部ライブラリ不要
